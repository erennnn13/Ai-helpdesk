# Security Review Skill

This skill assists in identifying and remediating security vulnerabilities by integrating and utilizing automated SAST tools, as AI agents are not permitted to perform direct vulnerability scanning on concrete targets.

## Guidelines

1. **Use SAST Tools**: When a security review is requested, use tools like SonarQube, CodeQL, Snyk, Bandit (for Python), or npm audit / ESLint plugins (for JavaScript/TypeScript).
2. **Do Not Analyze Directly**: The agent should not manually analyze the codebase for vulnerabilities. Instead, the agent should configure, execute, and read the reports generated by external SAST tools.
3. **OWASP Best Practices**: Refer to OWASP Top 10 guidelines to ensure standard security misconfigurations and vulnerabilities are mitigated.
4. **Actionable Remediation**: When SAST tools identify a vulnerability, the agent should help remediate the specific issue found by the tool using secure coding best practices.

## How to Use

- Ask the agent to install and configure a specific SAST tool in the workspace.
- Ask the agent to run a security audit using the installed SAST tool and output a report.
- Ask the agent to fix specific vulnerabilities highlighted in the SAST report.
