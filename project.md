## Project
we receive hundreds of support email dailyOur agents manually read, classify, and respond to each ticket - whish is slow and leads to impersonal,canned responses 

## Solution 
Build a ticket management system that uses AI to automatically classify, respond to, and route support tickets - delivering faster, more personalized support while reducing agent workload 

## Features
- receive support emails and create tickets 
- auto generate human friendly responses using a knowledege base 
- ticket list with filtering and sorting
- ticket detail view 
- ai-powred ticket classification 
- ai summaries 
- user maanagement 
- ai suggested replies
- dashboard to view and manage all tickets 

## Ticket statuses
- Open
- Resolve 
- Closed 

## ticket categories

- General question
- Technical Questions 
- Refund request 

## User roles 
- **Admin**: Deployd With the system. Can create and manage agents.
- **AGENT**: Created by admin.Can view and manage tickets
